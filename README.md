# Regression vs Classification of Fruits

This project demonstrates a simple Supervised Learning workflow using Python and scikit-learn, including both Regression and Classification models.

📊 Project Overview

In this project, we:
Generated synthetic fruit data (weight and volume)
Created meaningful class labels for classification
Built models for regression and classification:
1. Linear Regression
2. Logistic Regression
3. K-Nearest Neighbors (KNN)
4. Decision Tree
Made predictions on test data
Evaluated models using R² score (regression) and accuracy (classification)
Visualized the results (scatter plots, optional confusion matrix)

🧠 What I Learned
Difference between Regression vs Classification
How Logistic Regression, KNN, and Decision Tree work
Importance of feature labels and data structure
Model evaluation metrics: R², Accuracy, Confusion Matrix
Data visualization techniques using Matplotlib and Seaborn

🛠️ Tools & Libraries
Python
NumPy
Pandas
scikit-learn
Matplotlib
Seaborn

📈 Sample Results
Linear Regression R² Score: 0.85
Logistic Regression Accuracy: 0.90
KNN Accuracy (k=3): 0.88
Decision Tree Accuracy: 1.00

📌 Conclusion
This project demonstrates how different supervised learning models handle classification and regression tasks. The artificially generated dataset allowed testing model performance and understanding the strengths and limitations of each algorithm.
